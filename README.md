# エレメンタル・シンクロ（試作版）

4人協力の、属性チェイン・デッキ構築バトルです。ブラウザで遊べます。
サーバーは Node.js だけで動き、追加のパッケージは必要ありません。

## 自分のPCで動かす

1. Node.js（バージョン18以上）をインストールする
2. このフォルダでターミナルを開いて `npm start` を実行する
3. ブラウザで http://localhost:3000 を開く

1台のPCで複数人の動きを試したいときは、別のブラウザ（またはシークレットウィンドウ）で開くと、別のプレイヤーとして参加できます（セーブも別になります）。

## Render で公開する（友達と遊ぶ）

1. GitHub に新しいリポジトリを作り、このフォルダの中身をすべてアップロードする
2. https://render.com にログインし、「New +」→「Web Service」を選ぶ
3. 作ったリポジトリを選び、次のように設定する
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: Free
4. 「Create Web Service」を押す。数分で `https://〇〇.onrender.com` のURLが発行される
5. そのURLを開いてルームを作り、「招待リンクをコピー」で友達にリンクを送る

※ 無料プランでは、15分間だれも使わないとサーバーが止まります。次に開いたとき、起動に30秒〜1分ほどかかります。
※ 所持カードとデッキは各自のブラウザに自動保存され、ブラウザを閉じてもアップデートしても残ります。バックアップや別のPCへの移動は、タイトル画面の「セーブデータ」から、ファイルへの書き出し・読み込み（または引き継ぎコード）でできます。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `shared/data.js` | カード・役職・属性・敵・ステージのデータ。**バランス調整はここ** |
| `server/battle.js` | 戦闘ルール（予約 → 優先度順に一斉処理 → 敵の行動 → ターン終了） |
| `server/ai.js` | AIの味方の思考 |
| `server/index.js` | ルーム管理と通信 |
| `server/ws-lite.js` | WebSocketの最小実装 |
| `public/` | ゲーム画面（`client.js`）、ドット絵（`sprites.js`）、見た目（`style.css`） |
| `tools/sim.js` | AI4人で自動対戦させて勝率を出すツール（`npm run sim`。`node tools/sim.js 300 rare` でレア入りデッキ） |

## 調整しやすい数値（shared/data.js）

- `SYNC_MULT`：同じ属性を出した人数ごとの倍率（チェイン。端数は切り捨て）（1人1.0／2人1.2／3人1.5／4人2.5）
- `costMult`：コスト倍率（2〜3コスト×1.0、4コスト×1.2、5コスト×1.5。最終威力にかかる。6コスト以上は作らない）
- `affinity`：属性相性（有利2.0／不利0.5、光闇と火風水は等倍）
- `CARDS`：各カードの効果・優先度・`stats`（HP・攻撃力・回復力）・状態の持続ターン（`turns`）
- `ENEMIES`：敵とボスの部位（HP・防御・行動パターン）。`eagle_storm` の `ultimate` がラストターンの大技
- `HAND_START` / `HAND_MAX` / `DRAW_PER_TURN`：手札（最初5枚・上限5枚・毎ターン1枚）
- `ENERGY_START` / `ENERGY_MAX`：エネルギー（3から毎ターン+1、上限10）
- `DECK_SIZE`：デッキ枚数（10枚・同じカードは1枚まで・代表カードはステータス2倍）
- `FAME_MAX`：名声の上限（名声1につき追加報酬の確率1%）

数値を変えたあとに `npm run sim` を実行すると、AI4人での勝率・平均ターン数・ラストターンを耐えた割合を確認できます。
（現在：勝率 約70％、ラストターンを耐えた割合 約80％）

## バランス調整の前提（重要）

- ステージ1の固定報酬枠と名声枠には、10%の確率でレアカードが出ます（各役職：5属性×2枚＝10枚、合計40枚）。
- **ステージ1より後に追加する敵は、プレイヤーがこのレアカードを持っている前提でバランスを調整します。**
- 調整の基準デッキは「攻撃カードを敵の弱点属性で固め、それ以外はレアカード」のデッキ（`tools/decks.js`）です：`node tools/sim.js 300 adv ステージID`（レアカード10枚だけのデッキは `rare`）
- 参考：ステージ1は、初期デッキだと勝率 約75%、レアカードだけのデッキだと勝率 約100%。

| 役職 | 初期デッキのステータス（HP/攻撃力/回復力） | レア10枚デッキのステータス |
|---|---|---|
| アタッカー | 61 / 10 / 0 | 137 / 35 / 0 |
| デバッファー | 60 / 3 / 0 | 136 / 19 / 0 |
| タンク | 93 / 2 / 0 | 194 / 5 / 0 |
| ヒーラー | 55 / 0 / 15 | 132 / 0 / 39 |

## ドラゴン（全属性・5ステージ）

- ルームの「ステージ」で選べます（紅蓮竜・翠嵐竜・蒼海竜・聖光竜・冥闇竜）。いきなりボス戦です（ウェーブ制の戦闘はありません。ステージ1も嵐の大鷲だけ）。
- 本体：毎ターン全体攻撃（竜の息吹）／左足：威力の高い単体攻撃（踏みつけ）／背中の棘：毎ターン竜全体の攻撃力を永続で上げる（闘気の棘）
- 部位を壊すと、その行動が止まります。本体を倒せば勝ち。
- レアドロップは、そのドラゴンの属性のレアカード（8枚）から出ます。
- 強さは「攻撃カードを弱点属性で固め、それ以外はレアカード」のデッキ基準で、どのドラゴンも勝率 約61〜70%（初期デッキではほぼ勝てません）。`node tools/sim.js 300 adv dragon_fire` で確認できます。属性ごとの数値は `shared/data.js` の `DRAGON_TUNE` です。

## 報酬・レア度・名声カード

- レア度：コモン／アンコモン（初期カードの上位版「○○＋」）／レア／固有／名声カード
- ランダム報酬（2枠）：名声の書・10 5%／名声の書・5 10%／名声の書・1 10%／残り（75%）は通常のランダム報酬（初期カードは出ず、上位版（アンコモン）と報酬用のコモン）。数値は `RANDOM_DROP_TABLE`。
- 名声枠：各プレイヤーの代表カードの名声1につき1%で発生し、出た報酬はパーティ全員がもらえます。
- 固定報酬枠・名声枠のドロップ表：レア10%／名声の書・10 5%／名声の書・5 10%／名声の書・1 10%／残り（65%）は通常ドロップ。数値は `shared/data.js` の `DROP_TABLE`。
- 名声カード（名声の書・1／5／10）：デッキ編集画面でカードをクリックして裏返し、裏面の「+1」「+5」「+10」ボタンを押すと、その書を1枚使ってカードの名声を上げられます。戦闘では9コストで固定1ダメージなので、ほぼ役に立ちません。

## 難易度の基準（tools/balance.js）

`node tools/balance.js 100 [ステージID…]` で、3種類のAIの勝率を出せます。

- **準備して一斉攻撃するAI**（目標 約90%）：ボス戦のエネルギー8のターンまで弱点属性のカードを温存し、その間は持続するバフ・デバフや防御で耐える。エネルギー8のターンに4人全員が弱点属性のカードを出して4チェインで攻撃する（`tools/strategies.js`）。
- **適当に出すAI**（目標 低い）：出せるカードをランダムに出す。
- 賢いAI（参考）：ゲーム内のAIの味方と同じ。

| ステージ | 一斉攻撃AI | 適当AI | 賢いAI（参考） |
|---|---|---|---|
| 風鳴りの丘（初期デッキ・大鷲HP1380） | 93% | 0% | 50% |
| 紅蓮竜 | 92% | 2% | 100% |
| 翠嵐竜 | 86% | 4% | 98% |
| 蒼海竜 | 88% | 12% | 100% |
| 聖光竜 | 88% | 4% | 100% |
| 冥闇竜 | 87% | 0% | 97% |

ドラゴンは鱗が硬く（防御30）、ふだんの攻撃は通りにくい。防御ダウンと4チェインを重ねた一撃で崩す前提。10ターン目に「竜王の咆哮」（ラストターン）。

## 報酬の確定・部位破壊・速攻ボーナス

- 報酬は**敵を倒した瞬間（部位は壊した瞬間）**にサーバーで抽選して確定し、戦闘画面でドロップ演出が出ます。報酬画面は確定したものを見せるだけです。
- **部位破壊報酬**（ドラゴンのみ）：部位を壊すと1部位につき名声の書・1を参加者全員がもらえます。そのあと全滅しても持ち帰れます（`STAGES` の `partReward`）。
- **速攻ボーナス**（全ステージ）：決まったターン数以内に倒すとランダム報酬が1枠増えます（`SPEED_TURNS`：風鳴りの丘6／紅蓮竜8／翠嵐竜7／蒼海竜7／聖光竜7／冥闇竜8。賢いAIでだいたい半分が達成できる値）。
- **レア演出**：レアが出ると、倒した敵から金色の光の柱が立ち、画面が光って「RARE!」。全員の画面に「〇〇がレアを入手！」と通知が出ます。
- 受け取りは報酬ごとのID（`claimedRids`）で管理しているので、再接続しても二重にはもらえません。

## 危険度（★1〜★5）

- ルームでホストが選びます。ステージを★Nでクリアすると★N+1が解放（ホストのセーブで判定）。
- ★が上がると、敵の自己強化（棘・羽・猛り）の数値が上がり、敵の攻撃が当たった相手に毒・攻撃力ダウン・被ダメージアップが付きます（`DANGER`）。攻撃の回数が少ないステージ1は `dangerScale: 2.8` で強めにかけています。
- 報酬：★ごとにレア+5%、名声の書の確率アップ。★3・★4はランダム報酬+1、★5は+2。
- 一斉攻撃AIの勝率（`STAR=3 node tools/balance.js 60`）：

| | ★1 | ★2 | ★3 | ★4 | ★5 |
|---|---|---|---|---|---|
| ドラゴン（5体の平均） | 88% | 74% | 53% | 46% | 27% |
| 風鳴りの丘（初期デッキ・`dangerScale: 2.8`） | 91% | 約89% | 83% | 77% | 27% |

AIの味方は、危険度の毒（今かかっている毒と、これから付く毒）もダメージ予測に入れて行動します。

## 依頼

- 一人3つ（簡単・普通・難しい）。各自のセーブに保存され、ルーム画面で全員分が見えます。
- 勝利したときにサーバーが判定。達成すると報酬（簡単＝名声の書・5／普通＝名声の書・10／難しい＝レア確定。ステージ指定の依頼はそのステージのレアから）がもらえ、同じ難しさの新しい依頼に入れ替わります。
- 種類：ステージクリア、★2以上・★3以上でのクリア、誰も倒れずにクリア、部位を2つとも壊す、4チェインでとどめ、チェインの回数、役職ごとの活躍（与ダメージ・デバフ回数・挑発で引きつけた回数・回復量）。
- 役職の目安は `ROLE_GOAL`（`node tools/quest_stats.js 40` で測った、一斉攻撃AIが勝った戦闘の分布から決めた値）。

## 戦闘結果と「もう一度」

- 戦闘が終わると、MVP（与ダメージ＋回復＋バフ/デバフ×25＋ドロー×15＋挑発で受けたダメージ）・与ダメージの割合・最大チェイン数・撃破ターンを表示します。
- 「もう一度」：人間の全員が押すと、同じメンバー・同じステージで再出発。★はその場でホストが変えられ、初期位置は直前に挑戦した★です。

## ルームの決まりごと

- ホストの回線が切れて30秒戻らないと、つながっている次の人が仮のホストになります。元のホストが戻ってきたらホストを返します（自分で退出した場合は返しません）。
- 戦闘結果の画面を表示している間は、空き席に新しい人が参加できます。役職を選んで「準備OK」を押し、全員が「もう一度」を押すと一緒に出発します。
- 「もう一度」は、つながっている人全員が押した時点で始まります（押していない人が切断した場合も、その時点で判定し直します）。

## 固有カード

- デッキ10枚とは別の「固有枠」に最大3枚（デッキ編集の上部で選ぶ。`UNIQUE_MAX`）。今の4枚（聖剣解放・終焉の刻印・不落の城塞・女神の加護）は全員が最初から持っている（`STARTER_UNIQUE`）。
- 全属性：どのチェインにも参加し、どの敵の弱点も突く。基本ステータスはなし。素の効果は低く、全属性チェイン4で本来の強さになる（例：聖剣解放 10→28）。
- HPの下の青い「固有ゲージ」は、自分のカードがチェインに入るとたまる（2チェイン+1／3チェイン+2／4チェイン+4、カード1枚ごと。`GAUGE_GAIN`）。固有カード自身のチェインではたまらない。
- ゲージが満タン（`GAUGE_MAX: 26`、うまくチェインすると8ターン目前後）になると、固有枠のどれか1枚を使える（5エネルギー、1ターンに1枚）。使うとゲージは0に戻り、またためれば何度でも使える。AIの味方も使う。
- 勝率への影響（一斉攻撃AI）：ドラゴン平均 ★1 88%→91%、★3 53%→56%、★5 27%→32%（固有カードの分だけ簡単になる方針）。

## 撤退・全員が倒れたとき

- 戦闘画面上部の「撤退」で撤退を提案。つながっている人間全員が賛成すると、戦闘をやめてロビーに戻る（一人でも反対すると取り消し）。撤退するとその戦闘の報酬は何も持ち帰れない。
- 部位破壊の報酬は、壊した瞬間に演出と「獲得！」表示が出るが、所持カードに入るのは勝利か全滅で戦闘が終わったとき（撤退したら入らない）。
- 人間が全員倒れても、AIの味方が残っていれば、演出のあと自動で次のターンに進む。
